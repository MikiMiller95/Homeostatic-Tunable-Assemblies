# Figure 3

This directory contains the plotting code, simulation code, and helper functions used to generate `Fig3.pdf`. 
## Directory contents

```text
Fig3.py                    Main script that assembles and saves Fig3.pdf
Fig3B.py                   Plasticity-rule plotting helper
Fig3D.py                   Deterministic two-population rate simulation
Fig3SpikingSim.py          Spiking E-I simulation and population theory
helper_functions.py        Connectivity and covariance helper functions
RunFig3Spiking.py          Generates the long weight/rate time-course data
RunRateDynamics.py         Generates stable/unstable initial-condition data
RunDifferentInputaE.py     Generates the different-aE attractor data
Fig3data_taur8ms/          Data generated by RunFig3Spiking.py
RateDynamicsdata/          Data generated by RunRateDynamics.py
VaryaE/                    Data generated by RunDifferentInputaE.py
```

## Python dependencies

The scripts require Python 3 and the following packages:

```bash
pip install numpy pandas matplotlib scikit-learn
```

Run all commands from this directory so that the relative imports and data paths resolve correctly.


## Make data directories
```bash mkdir -p Fig3data RateDynamicsdata VaryaE ```

## Generate the simulation data

The current figure reads data from three directories. Run these scripts to regenerate those datasets:

```bash
python RunFig3Spiking.py
python RunRateDynamics.py
python RunDifferentInputaE.py
```

The scripts have the following roles:

| Script | Output directory | Data used in `Fig3.py` |
|---|---|---|
| `RunFig3Spiking.py` | `Fig3data_taur8ms/` | Long spiking-simulation weight and rate trajectories, plus population-theory trajectories |
| `RunRateDynamics.py` | `RateDynamicsdata/` | Stable and unstable initial-condition rate traces and deterministic rate-model traces |
| `RunDifferentInputaE.py` | `VaryaE/` | Final simulated weights used for the regression lines at different values of `aE` |

The current plotting script reads seeds `0–9` from `Fig3data_taur8ms/`, seeds `0–19` from `RateDynamicsdata/`, and seed `0` from `VaryaE/`. `RunFig3Spiking.py` currently generates 20 seeds even though `Fig3.py` uses the first 10.

## Generate the figure

After the required CSV files are present, run:

```bash
python Fig3.py
```

This saves:

```text
Fig3.pdf
```
